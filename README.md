# MATRIX Landing

This directory contains a premium, responsive storefront for the MATRIX brand. It uses semantic HTML, modular CSS, and small vanilla JavaScript for fast load and accessibility.

Files added:
- index.html — the main storefront
- src/styles.css — modern glassmorphism styles and responsive layout
- src/app.js — small client app that renders product cards from data
- src/data/products.json — sample products organized by value ladder
